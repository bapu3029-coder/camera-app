# Camera App

Web-based camera app with iPhone-style software features: Photo, Portrait, Square, Night and Video modes, burst, timer, flash, HDR, zoom, tap-to-focus exposure, grid and Photographic Styles.

## Run
Host with GitHub Pages (HTTPS is required for camera access) and open the page in Chrome or Safari.

## Limits
Hardware-only features (LiDAR, ProRAW, Cinematic, Action mode, ProRes) need a native iOS app.
